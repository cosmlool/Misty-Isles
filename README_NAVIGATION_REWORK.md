# Туманные острова — UI / navigation refresh

В архиве — обновлённый клиент поверх исходного проекта, серверный код оставлен без изменений.

## Что включено
- Увеличен базовый размер интерфейса и кликабельных элементов; добавлены более заметные состояния фокуса для клавиатуры.
- Верхняя панель теперь показывает HP, опыт, золото, кристаллы и самоцветы.
- Главное боковое меню сокращено: отдельная ссылка на инвентарь убрана; вещи доступны из страницы персонажа через «Снаряжение и вещи». Добавлен «Журнал».
- Кнопки и карточки получили более крупные отступы и типографику, адаптивная компоновка сохранена.
- Серверные файлы и протокол сообщений не изменялись; сохранённые данные сервера не включены в этот патч и не должны заменяться.

## Установка
1. Сделай резервную копию `C:\game\client` и `C:\game\server\data`.
2. Распакуй архив в отдельную папку.
3. Перенеси `client/src/main.ts` и `client/index.html` в существующий проект.
4. Не заменяй `server/src`, `server/data`, `.env` и lock-файлы.
5. В `C:\game\client` выполни `npm install`, затем `npm run build` и `npm run dev`.

## Важно о проверке
Сборка в среде подготовки не завершилась: установка npm-зависимостей зависла, после чего TypeScript сообщил об отсутствующих типах `estree` в неполной папке `node_modules`. Это не подтверждает ошибку исходников, но и не позволяет заявить, что production-сборка проверена. Удали только локальную папку `client/node_modules` в распакованной копии и выполни `npm install` при стабильном доступе к npm. Исходный сервер и его данные этот архив не заменяет.
