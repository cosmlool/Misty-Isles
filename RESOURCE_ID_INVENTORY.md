# Инвентаризация утверждённых resource ID Misty-Isles

Дата: 2026-11-28  
Ветка: `feature/resource-catalog-implementation-2026-11-26`  
Источник: `server/src/resourceCatalog.ts` рабочей ветки. Документ перечисляет существующие ID и их назначение; он не задаёт источники добычи.

## Минеральные материалы — 8 ID

- Сырьё: `stone`, `granite`, `obsidian`, `clay`.
- Заготовки: `stone_blank`, `granite_blank`, `obsidian_blank`, `ceramic_blank`.

## Металлы и металлургия — 30 ID

Существующие металлургические основы: `copper`, `iron`, `steel`, `deep_silver`, `astralite`.

- Рудное/исходное сырьё: `ore_copper`, `ore_iron`, `ore_deep_silver`, `star_core_fragment`. Для стали отдельной руды нет.
- Слитки: `ingot_copper`, `ingot_iron`, `ingot_steel`, `ingot_deep_silver`, `ingot_astralite`.
- Четыре универсальные заготовки каждого из пяти металлов: `metal_<metal>_plate`, `metal_<metal>_rod`, `metal_<metal>_wire`, `metal_<metal>_sheet`, где `<metal>` — один из пяти ID выше. Это 20 конкретных ID, генерируемых каталогом.
- Дополнительный обработанный материал: `charcoal`.

## Древесина — 9 ID

- Исходное сырьё: `wood_common`, `wood_strong`, `wood_rare`.
- Заготовки: `wood_blank_common`, `wood_blank_strong`, `wood_blank_rare`.
- Рукояти: `wood_handle_common`, `wood_handle_strong`, `wood_handle_rare`.

## Общие органические материалы — 3 ID

- `leaves`, `roots`, `wood_resin`.

## Текстиль — 4 ID

- Исходное сырьё: `plant_fiber`, `wool`.
- Обработанные материалы: `thread`, `fabric`.

## Кожа — 5 ID

- Исходное сырьё: `hide`, `rough_hide`.
- Обработанные материалы и заготовки: `processed_leather`, `leather_strip`, `leather_blank`.

## Кость и звериные материалы — 13 ID

- Исходное сырьё: `bone`, `claw`, `fang`.
- Обработанные основы: `bone_blank`, `processed_claw`, `sharpened_fang`.
- Заготовки/компоненты: `bone_plate`, `bone_spike`, `bone_fragment`, `claw_element`, `claw_hook`, `fang_tip`, `fang_inlay`.

## Комбинированные компоненты — 4 ID

- `reinforced_fastening`
- `reinforced_fabric`
- `bone_overlay`
- `reinforced_metal_node`

## Границы применения

- Перечень содержит 76 конкретных ID с учётом 20 металлозаготовок, генерируемых по шаблону.
- Это каталог ресурсов и полуфабрикатов, а не таблица дропа. Наличие ID не означает, что он уже выпадает с монстров или добывается в определённой зоне.
- Не включены legacy `FLDROP-...`, валюты, экипировка и рецепты.
- Не добавлялись новые материалы, названия, ID, рецепты или источники. Запрещённые и удалённые растения/грибы/алхимические компоненты, песок, заражённое зерно и другие снятые позиции не возвращаются.
- Сверка roster с целевой 32-зонной картой выполнена и записана в `PVE_ZONE_SPEC_CROSSCHECK.md`: утверждённого нового состава монстров/привязок в проверенных документах нет. Не назначать источники этих ID по legacy roster; вернуться к распределению только после появления утверждённой спецификации новых зон и состава монстров.


## Уточнение по источникам металлического сырья — 2026-11-28

- Источник металлической руды уже утверждён концептуально: её добывает Шахтёр. Это отдельная задача от реализованного пятиминутного цикла добычи кристаллов.
- В каталоге есть четыре сырьевых ID: `ore_copper`, `ore_iron`, `ore_deep_silver`, `star_core_fragment`. Реализованный `mine` пока выдаёт только кристаллы; добыча этих руд в коде не подключена.
- Точные правила рудной добычи (месторождения/выбор сырья, количество, длительность и условия) в проверенных спецификациях не заданы. Не переносить на них параметры кристального цикла без отдельного основания.
- Источники остальных сырьевых групп и PvE-привязка остаются нераспределёнными до появления подтверждённых спецификаций.
