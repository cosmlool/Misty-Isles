# Misty Isles — карта, городские вкладки и глобальные таймеры

## Что добавлено
- Карта мира в виде узлов городов: столицы рас и нейтральные города берутся из текущего каталога сервера. Можно отправиться в город или открыть городские службы.
- Панель быстрых переходов внутри города: лавка, аукцион, кузница/ремесло, задания, храм, гильдия, охота и Колизей.
- Глобальная панель таймеров: отображает перерыв между походами и заказы ремесла, включая доступность готового заказа для получения.
- Панель напоминаний справа с переходами к охоте, ремеслу, карте, заданиям и журналу.
- На узлах карты выделяются родной и текущий города.
- Серверный исходник не менялся; использованы существующие сообщения `travel`, `craftClaim` и текущие поля персонажа.

## Установка
1. Сделай резервную копию проекта и `server/data`.
2. Распакуй архив в отдельную папку для проверки.
3. Перенеси `client/src/main.ts` и `client/index.html` в существующий клиент. Серверные файлы менять не требуется.
4. В `client` выполни `npm ci`, затем `npm run build`; запускай сервер и клиент привычным способом.

## Важные границы текущей версии
- Походы в текущей серверной логике разрешаются мгновенно; глобальная панель показывает существующий 15-секундный перерыв между охотами, а не придуманную длительность экспедиции.
- Производственные таймеры используют существующее поле `finishAt`; готовый заказ нужно забрать кнопкой в панели или в разделе ремесла.
- Полноценная иллюстрированная карта будет отдельным этапом после согласования визуальных материалов.
