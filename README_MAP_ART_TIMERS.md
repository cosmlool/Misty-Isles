# Туманные острова — карта, маршруты и правый виджет

## Изменения
- Активные таймеры и напоминания объединены в одну фиксированную правую колонку и расположены друг под другом.
- На небольших экранах эта колонка становится обычным блоком над содержимым, чтобы не перекрывать игру.
- Карта мира получила визуальные маршруты между узлами, декоративные островные/горные слои и более выраженные карточки городов.
- Существующие действия путешествия, предпросмотра города, переходы к охоте/ремеслу/заданиям и получение готового ремесла сохранены.
- Серверная логика и серверные данные не менялись.

## Установка
1. Сделайте резервную копию `C:\game\client\src\main.ts` и `C:\game\client\index.html`.
2. Распакуйте архив в отдельную папку.
3. Скопируйте `misty/client/src/main.ts` и `misty/client/index.html` в соответствующие места рабочего клиента.
4. В `C:\game\client` выполните `npm run build`, затем запустите `npm run dev`.

## Проверка
Проверьте клики по кнопкам путешествия и «Услуги города», переходы по вкладкам города, кнопки таймеров и получение завершённого производства. Маршрутные линии — декоративная схема связей, не ограничивающая путешествия между столицами.
