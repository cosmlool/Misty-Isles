# Туманные острова — запуск в один клик (Windows)

## Быстрый запуск
1. Распакуйте весь ZIP целиком в папку, например `C:\game`. Не переносите только отдельные файлы.
2. Убедитесь, что установлен Node.js LTS (рекомендуется Node.js 20 или новее): https://nodejs.org/
3. Дважды нажмите `Запустить игру.bat`.
4. При первом запуске скрипт установит зависимости клиента и сервера по `package-lock.json`. Это требует интернета и может занять несколько минут.
5. При успешном старте браузер откроет `http://127.0.0.1:5173`. Сервер Colyseus использует порт 2567.
6. Для завершения используйте `Остановить игру.bat`.
7. Для диагностики используйте `Проверить игру.bat`; подробный журнал находится в `logs\launcher.log`.

## Важные сведения
- Сервер и клиент запускаются в отдельных командных окнах. Не закрывайте их, пока игра используется.
- Скрипт не убивает произвольные процессы Node.js. Если порт 2567 или 5173 уже занят, он остановится и сообщит об этом.
- Папка `server/data` содержит игровые сохранения. Делайте резервную копию перед заменой проекта и не переносите поверх неё пустую папку data из другого архива.
- Не распаковывайте обновление поверх работающей игры. Сначала остановите игру и сделайте резервную копию.
- Автоматическая установка зависимостей выполняется, только когда отсутствует соответствующая папка `node_modules`. Если `package-lock.json` изменился между обновлениями, удалите только `client\node_modules` и/или `server\node_modules` перед запуском, чтобы выполнить чистую установку по новому lock-файлу.
- Эта версия использует dev-сервер Vite для локальной разработки. Для публичного сервера или игры вне своего компьютера нужна отдельная production-настройка, HTTPS, правила firewall и управление процессами.

## Что проверяет запуск
- наличие Node.js 18+;
- наличие `client`, `server`, `package.json` и lock-файлов;
- доступность портов;
- фактическую готовность серверного порта 2567 и клиентского порта 5173 перед открытием браузера.

Скрипт не может автоматически исправить ошибку в коде или несовместимую схему протокола — он останавливается и оставляет сообщение для диагностики.
