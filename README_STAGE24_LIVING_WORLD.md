# Misty Isles — Stage 24: Living World

## Изменения
- Каталог активностей регионов теперь передаётся клиенту вместе с текущим активным событием.
- Раздел «Сводка событий мира» расширен календарём региональной ротации, перечнем зон и фракций.
- Добавлен справочник боссов и редких существ по всем охотничьим локациям с рекомендуемыми уровнями.
- Личная хроника показывает до 30 последних значимых записей, если они есть в истории персонажа.
- Добавлены стили карточек событий и записей хроники.

## Совместимость
- Не добавлялись поля PlayerSchema и не менялись форматы сохранений.
- Существующая ежедневная ротация, шанс появления боссов/редких противников, награды, репутация и фракционные механики сохранены.
- Справочник не гарантирует появление босса: фактическая встреча по-прежнему определяется серверной логикой охоты.

## Проверки
- Требуется локальная проверка запуска клиента и сервера; полная сборка Vite и браузерный smoke-test не заявляются.
