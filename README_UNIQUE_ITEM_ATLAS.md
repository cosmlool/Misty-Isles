# Misty Isles — уникальный атлас предметов

- Добавлено **149 отдельных SVG-иконок**, по одной на каждый ID из каталога `ITEMS` в `server/src/index.ts`.
- Иконки лежат в `client/public/assets/items/by-id/<item-id>.svg`.
- `itemIcon()` теперь сначала загружает точный ID; для неизвестных/будущих предметов оставлен безопасный fallback на категорийную иконку.
- Иконки локальные, не требуют сети и работают в магазине/инвентаре и везде, где используется `itemIcon()`.

## Установка
1. Сделай резервную копию проекта и `server/data`.
2. Перенеси `client/src/main.ts` из архива в свой клиент.
3. Скопируй `client/public/assets/items/` целиком, включая `by-id/`.
4. В `client` запусти `npm ci` и `npm run build`.
5. Проверь магазин, инвентарь, экипировку и подсказки.

Сервер и сохранения не менялись. SVG созданы программно как оригинальные векторные иконки; это уникальные варианты, а не отдельные вручную нарисованные растровые иллюстрации.
