# Stage 28 — единый релиз Misty Isles

Stage 28 объединяет исправления, ранее обсуждавшиеся как Stage 27.1, и развитие городов/NPC. Этот файл описывает текущую рабочую ветку; он не является заявлением о завершённом QA.

## Включено в рабочую копию Checkpoint 3
- Пять нейтральных городов переименованы в утверждённые названия с миграцией старых значений города, репутации и посещений.
- Формула улучшения колец приведена к утверждённой: одинаковая стоимость до +99, последний шаг +100 стоит 100 базовых цен.
- Уникальность экземпляра кольца проверяется в магазине, фракционном магазине, крафте и аукционе.
- Активный таймер экспедиции не сбрасывается при сетевом отключении.
- Каталог магазина фильтруется сервером по расе и профессии; полный каталог предметов сохраняется для отображения предметов персонажа.
- Восемнадцать постоянных городских жителей и три странствующих NPC с характерами и репликами; карточки и диалоговые реплики в городе.
- Резервный восьмой слот экипировки показан без назначения.
- Область инвентаря ограничена по высоте и прокручивается внутри себя.
- Базовый rate limit на регистрацию и вход.
- Основные JSON-хранилища переведены на атомарную запись через временный файл и `rename`; это защищает целостность файла при прерывании записи, но не устраняет синхронную нагрузку.
- В Corrective Update 1 админ-команды временно открыты всем аккаунтам по главному паспорту; только для тестирования, не для публичного сервера.
- Новые гостевые ID генерируются через Web Crypto UUID; гостевой endpoint проверяет формат идентификатора и включён в rate limit.
- Добавлена документация `/docs/`.

## Не завершено / требует решения или полного QA
- Полный аудит всех серверных операций с валютой, предметами и наградами.
- Надёжное восстановление состава групповых экспедиций после разрывов соединения.
- Формула стоимости/времени межгородского путешествия должна быть согласована и реализована; нельзя выдумывать цифры.
- Аудит рецептов и сокращение избыточного числа ресурсов без удаления региональных редкостей.
- Проверка всех фильтров и поведения subclass-предметов при смене активной профессии.
- Полная стратегия миграции JSON-хранилища на SQLite/PostgreSQL — после измерения и аудита данных.
- Консолидация CSS — только после визуальных тестов.
- Полные сборки зависимостей не выполнены в этой среде: `npm ci` превысил лимит ожидания. Проверена синтаксическая транспиляция TypeScript, но это не заменяет `tsc --noEmit` и Vite build.

## Дополнительный технический проход
- Основные прямые записи целевых JSON-файлов заменены единым helper атомарной записи.
- `client/scripts/audit-assets.mjs`: 192 ресурса проверены, ошибок нет.
- `client/scripts/verify-project.mjs`: 0 ошибок, 1 предупреждение о `creature-catalog.webp`, который не упоминается в манифесте.
- `server/src/index.ts`, `server/src/PlayerSchema.ts`, `client/src/main.ts`: синтаксическая транспиляция — 0 диагностик.

## Проверки этой рабочей копии
- ZIP Stage 27: исходный архив прочитан; CRC-проверка исходного архива успешна.
- JSON: `equipment_catalog.json`, `forgotten_lands.json`, `city_npcs.json` успешно разбираются.
- TypeScript syntax: `server/src/index.ts`, `client/src/main.ts`, `server/src/PlayerSchema.ts` — 0 диагностик синтаксиса при `transpileModule`.
- Полная типовая проверка и production build: не подтверждены. Установка зависимостей в offline-режиме остановилась из-за отсутствующего пакета в локальном npm cache; имеющиеся `node_modules` неполные. Это остаётся обязательной проверкой перед финальным Stage 28.
