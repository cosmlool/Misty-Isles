## Общие правила, которые уже реализованы

- На персонажа допускается одна рабочая гильдия; вступление с 20 уровня; повторная смена запрещена.
- На персонажа допускается одна боевая профессия; выбор с 40 уровня, с проверкой доступности по расе.
- Список рабочих гильдий закрыт: `blacksmith`, `miner`, `enchanter`, `trader`. Алхимик в этот список не входит.

## Утверждённые рамки Торговца

- Размещение: Золотые дюны.
- Не более двух экспедиций одновременно.
- Обменная экспедиция: 6 часов; автоматический случайный результат, использующий инвентарь Торговца.
- Экспедиция за очищенным кристаллом: 2 часа; требует очищенный кристалл от Шахтёра; ресурс не гарантирован; отмена запрещена.
- Награды экспедиций хранятся до получения у NPC.
- Гильдейский магазин обновляется раз в 24 часа, показывает 10–15 случайных позиций из подготовленного списка, оплата кристаллами, stock общий для гильдии; позиции с нулевым stock остаются видимыми.

Эти рамки не задают конкретный список торговых товаров, точные затраты, цены, таблицы случайных результатов и вероятности. Их нельзя придумывать в ходе технической реализации.

## Особые замечания по совместимости

- `craftSpecialty` всё ещё содержит исторические значения `smith/alchemist/relic` и отображаемое название «Алхимик». Это старый контур специализации ремесла, не новая рабочая гильдия. Не удалять без отдельной проверки существующих сохранений, UI и зависимостей.
- Наличие четырёх ID гильдий не означает, что все четыре сервисных контура реализованы.
- Аудит не менял игровой код, данные, баланс, рецепты, дропы, сохранения или PR state.

## Следующие безопасные действия

1. Найти в утверждённых документах/данных подготовленный список товаров Торговца, предметы-инпуты экспедиций, outputs и таблицы результатов. Если они отсутствуют — оставить этот пробел явно зафиксированным.
2. Не присоединять руду к циклу кристаллов; отдельная добыча руды ждёт параметров.
3. Не придумывать услуги Зачарователья, пока нет его предметной спецификации.
4. Не удалять legacy `craftSpecialty/alchemist` до аудита обратной совместимости.
