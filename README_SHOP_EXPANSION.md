# Misty Isles — расширение магазина и эффекты колец

## Что изменено
- В серверный каталог добавлены новые виды оружия для разных профессий и универсальные варианты для поздних уровней.
- Добавлены дополнительные комплекты брони от начальных уровней до высокоуровневых регионов.
- Добавлены новые кольца с эффектами, которые используют существующие боевые и наградные механики: атака, защита, критический шанс, опыт, золото после охоты и восстановление здоровья после победы.
- Старые кольца, у которых не было описаний, получили понятные описания и мемные фразы в духе мира игры.
- Иллюстрация в `assets/concept/ui-art-direction-reference.png` — референс направления оформления, не готовый игровой атлас спрайтов. Она не подключена как фоновая картинка всего интерфейса, чтобы не заменять рабочие кнопки и панели плоским изображением.

## Установка
1. Сделайте резервную копию текущего проекта, особенно `server/data`.
2. Распакуйте архив в отдельную папку.
3. Перенесите `server/src/index.ts` в свой проект, сохранив структуру каталогов.
4. В папке `server` выполните `npm ci`, затем `npm run build`.
5. Запустите сервер и проверьте вкладки магазина: оружие, броня и кольца. Покупки колец используют существующие правила оплаты кристаллами; оружие и броня — существующую валютную логику магазина.

## Баланс и совместимость
- Новые предметы имеют уникальные ID; уже существующие ID не переименованы.
- Не изменялись формат сохранений, схема игрока и протокол Colyseus.
- Для эффектов использованы типы, которые уже учитываются в боевой формуле: `attack`, `defense`, `crit`, `xp`, `gold`, `lifesteal`.
- Полную интеграцию отдельных иллюстраций для каждого предмета, аватара и локации нужно делать отдельным этапом через атлас спрайтов и привязку к ID предметов. Большой концепт-скрин не следует использовать вместо интерактивных элементов.
