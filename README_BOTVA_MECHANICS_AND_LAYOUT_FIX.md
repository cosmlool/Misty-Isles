# Сборка: анализ механик и исправление правой панели

## Изменения в этой сборке
- Исправлены правила раскладки правой панели: на широком экране для неё резервируется отдельное место, чтобы таймеры и напоминания не перекрывали основной контент; на узком экране панель переходит в поток страницы.
- Добавлен `tools/Diagnostics-Game.ps1`, сохранённый в UTF-8 с BOM. Скрипт проверяет наличие файлов, версии Node/npm и локальные порты 2567/5173. Он не запускает бои, покупки или изменения персонажа и не меняет игровые сохранения.
- Добавлен корректно названный `Запустить игру.bat`, который вызывает существующий `tools/Start-Game.ps1`.
- Сохранены исходные механики Phaser + Colyseus; серверные формулы не менялись в этой сборке.

## Что удалось наблюдать в видео Botva-Online
- Экран тренировки показывает несколько характеристик, текущее значение, цену, среднее/целевое значение, скидку и общую стоимость.
- Экран боя показывает характеристики обоих участников, здоровье, ход боя, урон и оставшееся здоровье.
- Отдельный экран характеристики «Сила» перечисляет базовое значение и ряд бонусов от разных источников.

## Что НЕ следует считать подтверждённым
Видео и скриншот не раскрывают однозначно точную формулу: какие бонусы складываются, какие перемножаются и какие влияют на отображение отдельно. Поэтому в этой сборке формула силы не выдумана и серверный расчёт не заменён. Следующий шаг для точного баланса — снять значение до/после одной тренировки и до/после надевания одного предмета.

## Запуск и диагностика
1. Распакуйте архив в отдельную папку, не поверх текущего рабочего проекта.
2. Запустите `Запустить игру.bat`.
3. Для отчёта диагностики запустите `tools\Diagnostics-Game.ps1` через PowerShell из папки проекта. Отчёт появится в `logs`.
4. Проверка синтаксиса/сборка проекта в этой среде не выполнялась; проверьте проект у себя и пришлите полный вывод, если возникнет ошибка.
