# Туманные острова — этап 2: иллюстрированные города и регионы

## Что добавлено
- 4 иллюстрированные расовые столицы (отдельные WebP-файлы).
- Иллюстрации лесов, гор, пустошей, побережья, подземелий, охотничьих мест, порта и городских интерьеров.
- На странице «Город» баннер выбирается по расе персонажа; торговые и ремесленные карточки получили тематические фоновые иллюстрации.
- На странице «Охота» у каждой группы регионов появился иллюстрированный заголовок. Выбор региона сопоставляется по имени с локальным набором иллюстраций; неизвестные регионы используют лесной фон.
- Все новые изображения находятся в `client/public/assets/locations/` и не требуют сетевых запросов.
- Игровые обработчики и серверная логика не изменялись.

## Установка
1. Сделайте резервную копию проекта и `server/data`.
2. Распакуйте архив в отдельную папку для теста.
3. В `client` выполните `npm ci`, затем `npm run build`.
4. Запустите сервер и клиент. Проверьте страницу города, охоту, переключение между регионами и адаптивность окна.

## Проверка в среде сборки
- TypeScript: `tsc --noEmit` — успешно.
- Vite production build: не завершён в подготовительной среде из-за отсутствующего optional-пакета `@rollup/rollup-linux-x64-gnu`; это ограничение набора зависимостей в подготовительной среде. На Windows следует выполнить `npm ci` и `npm run build`.
