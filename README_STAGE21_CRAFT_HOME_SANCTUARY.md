# Stage 21 — Ремесло, жилище и святилище

## Что изменено

### Ремесленная мастерская
- Перестроен каталог рецептов: отдельные карточки с выходным предметом, материалами, количеством в инвентаре, требуемым навыком и временем.
- Добавлен видимый статус доступности рецепта и занятости очереди.
- Очередь показывает результат заказа, обратный отсчёт и индикатор прогресса.
- Сохранены серверные действия `craft`, `craftQueue`, `craftClaim` и `craftSpecialty`.
- Лимит очереди и все требования по материалам по-прежнему проверяются сервером.

### Личное жилище
- Каждая постройка получила уровень 0–10, шкалу прогресса, описание фактического бонуса и цену следующего уровня.
- Клиентская цена приведена к серверной формуле: `floor(650 * (level + 1)^1.85)`.
- Сохранены серверные действия и существующие ключи построек: `training`, `garden`, `library`, `workshop`, `warehouse`.

### Святилище и эффекты
- Святилище показывает текущий активный бафф, время окончания, стоимость и доступные благословения.
- На странице эффектов дополнительно отображается действующий серверный бафф персонажа, если он ещё не представлен в массиве активных эффектов.
- Сохранены серверное действие `buff`, три вида баффов и длительность, заданная сервером.

## Совместимость
- `server/src/index.ts`, `PlayerSchema.ts`, Colyseus-сообщения и `server/data` не изменялись.
- Не добавлялись новые поля схемы и серверные протоколы.
- Сохранены существующие идентификаторы навигации, запускатели и диагностические скрипты.
- Добавлены адаптивные стили для широкого и узкого экрана.

## Проверки
- TypeScript transpile/syntax check пройден для `client/src/main.ts`, `server/src/index.ts` и `server/src/PlayerSchema.ts`.
- Проверка полного typecheck/Vite build не завершена: `npm ci` превысил лимит времени; при повторном локальном `tsc` отсутствовал тип `estree` из неполной установки зависимостей.
- Полный браузерный smoke-test не выполнялся в этой среде. Запусти `VERIFY_PROJECT.bat` и `npm run verify:project` после установки зависимостей.
