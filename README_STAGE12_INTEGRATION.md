# Этап 12 — интеграция иллюстраций и исправление компоновки

Эта сборка продолжает Stage 11 и включает весь проект `game/` (клиент, сервер, данные и ассеты).

## Исправления

- Панель активных таймеров и напоминаний переведена из фиксированного позиционирования в поток страницы. Так она не должна перекрывать игровую область и кнопки на широких экранах.
- Убрано резервирование лишнего левого поля у основного layout; сохранены отдельная боковая навигация и адаптивная сетка.
- Атлас снова получает реальное фоновое изображение: `client/public/assets/illustrations/atlas-background.webp`. Оно вырезано из существующей иллюстрации архипелага, чтобы убрать внешнюю рамку и кнопку, мешавшие использованию в качестве фона.
- Точки карты остаются отдельными интерактивными DOM-элементами поверх изображения, а не частью фоновой картинки.
- Для портретов, монстров и предметов закреплено вписывание изображения без принудительного обрезания/растягивания.
- Добавлена адаптивная раскладка для панели таймеров, карты и боковой навигации.

## Проверка

Из `client/`:

```bat
npm ci
npm run audit:assets
npm run build
npm run dev
```

Затем открыть `http://localhost:5173/asset-gallery.html` и вручную проверить страницы персонажа, карты, магазина, инвентаря, охоты и заданий.

В этой среде `npm ci` не удалось завершить из-за сетевого тайм-аута при обращении к npm registry, поэтому здесь не подтверждалась сборка Vite. Успешный аудит файлов не заменяет визуальную проверку в браузере.

## Важно

Этап исправляет размещение и подключение имеющихся иллюстраций, но не подменяет все низкоразрешённые портреты и предметные иконки новыми авторскими исходниками. Маленький исходник нельзя превратить в детализированную иллюстрацию одним CSS.
