# Туманные острова — цельная версия с иллюстрациями

## Что подключено

- Локальные иллюстрации из `client/public/assets/illustrations/` для фона мира, блока персонажа, карты и лесного региона.
- Иллюстрированный баннер персонажа в реальном экране персонажа, с именем, расой, профессией и уровнем из данных игрока.
- Иллюстративные фоны для основного окна, карты, городского приветствия и предметных рамок.
- Сохранены существующие игровые экраны, обработчики, сообщения Colyseus, серверный код и данные `server/data`.
- Исправлена явная типизация узлов карты, чтобы TypeScript проверка проходила.

## Установка на Windows

1. Сделайте резервную копию текущего проекта и отдельно `server/data`.
2. Распакуйте архив в новую папку, затем перенесите файлы в рабочую папку либо сначала протестируйте отдельно.
3. В терминале сервера выполните `npm ci`, затем `npm run dev`.
4. В терминале клиента выполните `npm ci`, затем `npm run dev`.
5. Откройте адрес Vite, который покажет терминал (обычно `http://localhost:5173`).
6. Для проверки клиентской сборки выполните `npm run build` в папке `client`.

`node_modules` намеренно не включены в архив: npm устанавливает зависимости под вашу Windows-среду из lock-файлов. Не удаляйте `server/data` и не заменяйте его пустой папкой — там могут быть сохранения игроков.

## Проверка в среде подготовки

- `tsc --noEmit` для клиента прошёл после исправления типа узлов карты.
- Vite production build не завершился в Linux-среде из-за отсутствующего платформенного optional package `@rollup/rollup-linux-x64-gnu`; npm-реестр в этой среде недоступен для корректной переустановки. Это ограничение среды, не подтверждение полной production-сборки.
- Серверная логика не менялась. После установки проверьте вход, навигацию, карту, магазин и действия персонажа на копии данных.
