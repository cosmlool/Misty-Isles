# Changelog — Stage 28

## 2026-11-08 — первые изменения рабочей ветки
- Добавлены утверждённые названия пяти нейтральных городов и миграция старых значений в сохранениях.
- Сохраняются городская репутация и флаги первого посещения при миграции названий.
- Установлена стоимость улучшения кольца: цена покупки для всех шагов до +99; 100× цены для +99 → +100.
- Добавлена защита от повторного получения того же кольца через магазин, фракционные предложения, крафт и аукцион.
- Сетевой разрыв больше не сбрасывает состояние/окончание таймера экспедиции.
- Введён серверный `shopItems`, отфильтрованный по расе и профессии; клиент получает его отдельно от полного каталога предметов.
- Добавлены 18 постоянных NPC и 3 странствующих NPC, городские карточки и диалоговые реплики.
- Добавлен визуальный резервный восьмой слот экипировки без назначения.
- Добавлена внутренняя прокрутка инвентаря.
- Добавлен базовый лимит 10 попыток входа/регистрации на IP за 15 минут в одном процессе.
- Добавлен переносимый комплект документации в `/docs/`.

## 2026-11-08 — защита JSON-сохранений
- Основные JSON-хранилища переведены на атомарную запись: запись полного снимка во временный файл рядом с целевым и последующая замена через rename.
- Прямые записи целевых JSON-файлов через `writeFileSync` заменены на общий helper.
- Это уменьшает риск обрезанного файла при аварийной остановке во время записи; синхронная нагрузка на Event Loop остаётся и требует отдельного измерения/миграции БД.
- Синтаксическая транспиляция `server/src/index.ts`, `server/src/PlayerSchema.ts`, `client/src/main.ts`: 0 диагностик. Полные сборки не выполнены из-за отсутствующих npm-пакетов в доступном окружении.

## 2026-11-08 — закрытие тестовых админ-команд
- Серверная команда `admin` теперь требует явного совпадения player ID с allowlist `ADMIN_PLAYER_IDS`. По умолчанию список пуст, административные команды отклоняются.
- Добавлена инструкция настройки доступа `server/ADMIN_SETUP.md`; текст клиентской панели уточнён.
- Новые гостевые ID создаются криптографически стойким Web Crypto UUID; `/auth/guest` проверяет формат идентификатора и также ограничен rate limit.
