# Административная панель — тестовый режим Stage 28

По главному паспорту проекта административные команды временно открыты всем аккаунтам в текущей тестовой сборке. Настройка `ADMIN_PLAYER_IDS` в этой версии не используется.

**Важно:** открытая панель позволяет любому вошедшему пользователю выдавать себе золото, кристаллы, опыт, материалы и менять состояние собственного персонажа. Не публикуй этот сервер в интернете и не используй его как production-сборку.

Перед публичным запуском необходимо вернуть серверную проверку прав администратора, настроить allowlist доверенных player ID и проверить каждую административную операцию. Скрытие кнопки в клиенте не является защитой.
