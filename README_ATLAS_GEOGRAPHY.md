# Атлас Туманных островов — география и навигация

## Что изменено
- Карта мира перестроена из сетки карточек в атлас с фиксированными географическими позициями городов.
- Добавлены отдельные силуэты островов, морские линии, лесные/горные условные знаки, подписи регионов, компас и масштаб.
- Маршруты рисуются между узлами: морские пути пунктиром бирюзового цвета, сухопутные тракты — золотистым пунктиром.
- Состояния узлов визуально различаются: текущий город, родная столица, нейтральный порт и остальные столицы.
- У каждого узла есть действия путешествия и открытия городских служб. Используются текущие обработчики `travel` и `cityPreview`.
- Макет адаптируется под узкие экраны. Правая колонка таймеров/напоминаний и серверные исходники сохранены из предыдущей рабочей версии.

## Установка
1. Сделайте резервную копию проекта и `server/data`.
2. Распакуйте архив отдельно.
3. Перенесите `client/src/main.ts` и `client/index.html` в рабочий клиент.
4. В `client` выполните `npm ci`, затем `npm run build`.
5. Запустите клиент и сервер, проверьте узлы карты, путешествие и открытие служб.

## Проверка
TypeScript source успешно проходит синтаксическую транспиляцию. Полная проверка `tsc --noEmit` в среде сборки заблокирована неполным локальным каталогом типов `estree`; повторите `npm ci` в проектной среде и запустите `npm run build`.

Карта сейчас использует стилизованные векторные иллюстрации, без внешних картинок. Следующий этап — заменить условные знаки на уникальные изображения городов и локаций.
