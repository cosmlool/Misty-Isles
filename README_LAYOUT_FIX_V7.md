# Misty Isles — Botva Mechanics Layout Fix v7

## Что исправлено
- Удалено влияние старых фиксированных отступов `margin-left` / `margin-right` у общей игровой сетки.
- Правая панель таймеров и напоминаний возвращена в третью колонку `.layout`, вместо `position: fixed`.
- Общая компоновка: левая навигация / центральная страница / правая колонка.
- Исправлена внутренняя сетка страницы персонажа, чтобы экипировка и сумка не сжимались до узких столбцов.
- На странице создания персонажа портреты рас помещены в отдельную область с `background-size: contain`, без грубого обрезания.
- Добавлены корректно названные `Запустить игру.bat` и `Остановить игру.bat` (старые записи архива сохранены).

## Установка
Распакуй архив в отдельную папку. Запускай `Запустить игру.bat`.
Не распаковывай поверх предыдущей версии.

## Проверка
ZIP integrity и наличие файлов проверены. Браузерный визуальный запуск в этой среде не выполнялся; проверь страницу персонажа и экран выбора расы локально.
