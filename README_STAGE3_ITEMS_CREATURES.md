# Туманные острова — этап 3: предметы и существа

## Что добавлено
- Локальные иллюстрированные каталоги экипировки, кулонов/расходников, существ и трофеев в `client/public/assets/illustrations/`.
- Иллюстрированный баннер арсенала непосредственно на странице магазина.
- Иллюстрированный баннер бестиария непосредственно на странице охоты.
- Существующие ID предметов, обработчики покупки/экипировки и серверная логика сохранены.
- Изображения загружаются локально и не требуют внешних запросов.

## Проверка
- Проверьте наличие всех 4 WEBP в `client/public/assets/illustrations/`.
- Выполните в `client`: `npm ci`, затем `npm run build`.
- Откройте магазин и охоту: оба экрана должны показывать новые иллюстрированные баннеры.

Примечание: каталожные изображения — художественные панели, а не уникальные отдельные спрайты для каждого предмета. Существующие предметные SVG и их ID не заменялись.
