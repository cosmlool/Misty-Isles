# Диагностика Stage 12 и исправления Stage 13

## Найдено в архиве Stage 12

1. `index.html` содержал несколько последовательных CSS-проходов, которые переопределяли друг друга. В результате размеры карты и портретов зависели от порядка правил.
2. Одна и та же иллюстрация архипелага использовалась одновременно как фон всей страницы, декор верхней панели и фон самой карты. `city-panel.webp` также повторялся как декор разных страниц. Это и создавало ощущение, что интерфейс сделан из одной картинки.
3. Карта принудительно растягивалась до `background-size: 100% 100%` и имела большую фиксированную высоту, искажая пропорции.
4. Некоторые файлы персонажей действительно очень малы: монстры примерно 60–65 × 165 px, NPC примерно 75 × 160 px. CSS не может добавить им утраченные детали; эти файлы нужно заменить полноценными иллюстрациями.
5. Иконки предметов — SVG 64×64 с повторяющейся рамкой/шаблоном и различающимися силуэтами. Они различимы по форме, но не являются высокодетализированными рисованными иконками.
6. В окружении архива `npm run build` остановился до сборки: `TS2307 Cannot find module 'colyseus.js'`. `npm ci` в этой среде превысил лимит ожидания сетевого доступа к npm registry; это не подтверждает, что проект исправен.

## Исправления Stage 13

- Отключены повторяющиеся глобальные подложки карты и города; иллюстрация архипелага остаётся в окне карты.
- Удалено принудительное растяжение карты; используется сохранение пропорций и адаптивное окно.
- Убрана повторяющаяся иллюстрация кузницы с городских карточек.
- Зафиксировано отображение портретов и предметов без растягивания/обрезания.
- Добавлен этот отчёт, чтобы отличать исправления CSS от задач, которые требуют новых исходных иллюстраций.

## Проверка

Из `client/`: `npm ci`, `npm run audit:assets`, `npm run build`. В этой среде аудит ассетов можно выполнить, но сборка не подтверждена из-за недоступной зависимости `colyseus.js`. До релиза нужно проверить браузером карту, персонажа, охоту, магазин, инвентарь и клики.
