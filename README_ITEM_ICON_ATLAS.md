# Атлас иконок предметов — Туманные острова

## Что подключено
- В клиент добавлен `client/public/assets/items/` — SVG-атлас из 48 отдельных рисованных иконок: оружие, броня, кольца, зелья, материалы и универсальные предметы.
- Магазин показывает крупную иллюстрацию в карточке каждого предмета.
- Инвентарь использует те же изображения, чтобы визуальный образ совпадал между магазином и вещами.
- Функция `itemIcon()` связывает ID предмета с вариантом иконки детерминированно: один и тот же ID всегда выбирает один и тот же вариант внутри категории. ID также присутствует в атрибуте `data-item-id` и подсказке элемента.
- Изображения локальные, не требуют внешних сетевых запросов. Игровые ID, цены, эффекты и серверные обработчики не менялись.

## Установка
1. Сделайте резервную копию проекта и `server/data`.
2. Скопируйте `client/src/main.ts` и `client/index.html` из архива в существующий клиент.
3. Скопируйте каталог `client/public/assets/items/` целиком.
4. В `client` выполните `npm ci`, затем `npm run build`.
5. Запустите клиент и откройте Магазин и Инвентарь.

## Примечание
Это первый подключённый локальный набор стилизованных SVG-иконок. Это не финальная уникальная ручная иллюстрация каждого предмета; следующий этап — нарисовать отдельные иконки для каждого ID и расширить атлас без изменения игровой логики.
